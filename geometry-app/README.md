# Geometry · 几何证明探究

通过动态几何、条件变化、证明依赖、精确反例和 AI 思路批改，理解条件与结论之间的关系。

应用代码位于仓库的 `geometry-app/` 目录。以下命令均在该目录运行。

## 当前运行

当前电脑已经安装项目依赖。在本目录打开终端并执行：

```powershell
npm run dev
```

日常使用双击外层 Geometry 文件夹中的唯一启动脚本 `启动 Geometry.cmd`，浏览器打开 <http://127.0.0.1:3000/>。使用期间保留启动窗口，关闭窗口或按 Ctrl+C 会停止本次启动的本机服务。再次双击打开已运行的网站，不重复占用端口。

本机入口3000、内部网页服务3101、Python计算服务8001均只监听 `127.0.0.1`。入口保留静态资源压缩与缓存、API转发和服务凭据边界。本机启动与恢复逻辑位于 `scripts/local.py`、`local_runtime.py`、`local-gateway.mjs`、`local-assets.mjs`；Windows Job Object负责关闭窗口和启动失败时的进程清理，单服务退出后按退避间隔恢复。

内网穿透及临时公网分享已移除，不再下载或启动隧道、不生成临时网址、不检测分享状态。页面不再依赖分享会话，也不再根据本机启动/关闭清空访客记录。原有本机浏览器题目、变式、设置和记录继续使用原来的存储键；AI Key仍由原凭据组件管理。

启动器首次或网页输入变化时构建页面，以后复用编译结果。本机日志位于 `.local/local/`。开发模式可运行 `npm run dev:all`，启动日常模式前需先退出占用相同端口的开发服务。

当前只提供本机运行。网页构建所需的 Cloudflare/Vinext/Wrangler 是本机使用的框架运行依赖；启动时不会发布网站或创建公网入口。

首次在另一台 Windows 电脑安装，需要 Node.js >=22.13，然后在项目目录执行：

```powershell
node scripts/setup.mjs
npm run dev
```

安装脚本从官方 npm/PyPI 获取依赖，将 Python 与缓存放在项目内，不注册系统 Python 或修改系统 PATH。非 Windows 环境需先安装 Python 3.12，再执行同一脚本。

也可以用系统 Python 3.12 手动安装：

```powershell
npm ci
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
npm run dev
```

## 页面与使用

- 首页：半透明玻璃与古典几何底图，展示产品能力和本浏览器真实记录；没有“开始探究”按钮。
- 探索：复古手账拼贴，五道已核验题目；“画图”在新标签打开 GeoGebra 官方画板，不下载额外工具包。“新建”进入图片识别、补充对话和题目核对流程；自己的例题从第六张卡片开始排列，卡片外有删除入口。
- 新建例题：上传图片或 PDF 后由 AI 读取题目，再核对/修改点名、已知条件和求证目标。识别不全时可继续告诉助手要增加什么；整理失败会保留已读内容和具体缺项。只有完整表达且条件可满足的题目才能创建，未支持的条件不悄悄丢弃。保存仅保留题目及分析数据，不把上传原图写入题库。
- 工作台：可全屏操作动点，显示当前长度/角度。图形自由度由当前条件自动决定，不再手动选择动点、定点或从动点，也不再显示“已确认”或旧确认按钮。课题进入和条件切换后自动检查与分析。证明默认折叠；一题多解、依赖和已核验反例保留。学生可用自然语言、图片或 PDF 提交思路给 Geometry小助手批改，与 AI 页共用所选服务商的 API Key。
- 自建题复用同一个工作台，可增加、编辑、删除、开关条件并保存；AI 新提议的证明明确标为候选，对能正确编码的步骤分别核验。教学模板和 Newclid 搜索只在各自实际支持范围内返回，任意图题不保证有多条已验证证明。
- 说明：红黄蓝风格派，四张卡片可进入详情；隐私政策、数据使用、使用条款待完善，微信联系方式为 ric09990。
- AI：独立对话页面，支持文字、图片、PDF 和文本文件；与探索课题批改共用会话 Key，可选官方联网搜索。网页填写 Key 即可使用，详见 [配置方法](docs/ai-setup.md)。
- 左侧顺序为首页、AI、探索、说明；各页对齐一致。设置提供中文/English、点标签和减少动态效果；字号放大功能已移除。

首版为本机访客模式，账号与跨设备同步尚未加入。保存记录取决于当前浏览器的本地存储，切换浏览器、清除站点数据或私密窗口会影响记录。

## 等腰三角形验收

1. 打开等腰三角形课题，自动核验；展开“证明与分析”查看 HL、SSS 及实际搜索结果。
2. 直接取消 AD⊥BC，保留中点。自动重新分析；HL 路线失去依据，SSS 仍成立。
3. 再取消中点，自动搜索并精确核验反例。点击查看反例可在画板显示。
4. 重新勾选条件，画板约束、分析和版本同步更新。已过期的 AI 批注不能当作新条件下的评价。

教学路线与 Newclid 原始返回分开记录，不能把教学模板当成搜索结果。没有找到证明，不等于结论错误；原证明失去依据，也不等于结论错误。

## 实际接入与验证

详见 [六个引擎的版本、许可和状态](docs/engines.md)、[Newclid 兼容适配](docs/newclid-compatibility.md) 和 [已确认的产品决定](docs/decisions.md)。

六个几何开源项目均已实际调用。NiceGeo 官方源码已在本机编译，支持范围内检查提交的证明脚本；Z3 约束核验另外展示。原学生结构化表单已按用户要求删除，NiceGeo 正式后端接口和运行程序保留。安装与运行范围见 [NiceGeo 接入记录](docs/nicegeo-integration.md)。早期协议验证使用隔离上游测试；此后在用户明确授权下，使用用户提供的DeepSeek Key完成了真实图片识题、补充对话、AI页作业批改和探索页证明批改。真实联网请求也已发起，但搜索相关性不作为已通过的质量保证。OpenAI、Anthropic和Gemini仍仅通过隔离协议测试，不能称为真实付费调用验收。完整范围及PDF下载未验收项见 [验证记录](docs/verification.md)。

运行检查：

```powershell
npm run typecheck
npm run build
npm run test:frontend
.\.venv\Scripts\python.exe -m pytest -q tests
```

自动测试包含5道案例、核心条件切换、精确反例、依赖传播、真实 Newclid 证明、矛盾条件、不支持关系和服务凭据。实际结果见 [测试记录](docs/verification.md)。首次安装脚本尚未在另一台机器验证。
