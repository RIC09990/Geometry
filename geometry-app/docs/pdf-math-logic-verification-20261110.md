# PDF、数学排版与网站逻辑验收（2026-11-10）

## 已修复的原因与行为

- 截图中的“独立复核暂未完成”来自评分流程，发生在 PDF 渲染之前。旧流程将导出和评分绑定，还会因首轮题号与复核题号不同、复核纠正了首轮 OCR 读数而拒绝结果。没有该次请求的诊断记录，因此不能断定截图当时触发了哪一条检查。
- PDF 是独立的本地文档操作。已有回复可直接调用 `POST /api/ai/export-pdf`，无需密钥、模型请求或联网搜索。没有评分也可导出，不生成虚构分数。模型可用简短的 `exportPdf` 字段请求生成完整正文的 PDF。
- 评分继续检查最终分数、逐项判断和明显错误的数值等式。删除把首轮模型输出当作可靠原文的检查，复核不再额外限制为 40 秒。模型和最高思考等级保持 `deepseek-flash / max`。
- 导出失败保留正文并提供重试；截断的模型输出不会自动标成完整报告。单个不支持的公式不再使整份文档失败，完整原式带明确标签保留。
- 数值结果用受限表达式解析与 KaTeX 排版，支持根式、分式、乘方和嵌套表达式，不执行字符串。
- 视觉验收另发现 KaTeX 渲染器与 CSS 版本错配：`rehype-katex` 生成 0.16.47 的类名，却导入直接依赖 0.19.1 的样式；不等号的斜杠叠加定位因此失效。统一为渲染器使用的 0.16.47，并对真实输出类名与 CSS 匹配增加回归。
- 导出附件固定为生成这条回复时使用的图片组，后续新题不会混入旧报告。网络错误恢复原始文本和附件；附件未读取完成不能发送。

## 数学核验与接口修复

- 坐标归一化现在同时检查前提和目标：绝对长度目标不能借用单位长度，绝对坐标目标不能借用固定原点，有向圆弧目标不能借用镜像方向。
- AI 每一步核验使用该步骤自身作为目标。最终结论比较相关数值、坐标、权重和圆弧方向；`AB=1` 的证明不能认证 `AB=2`。
- 单步接口对未编码文字或求解类目标返回结构化的 `cannot_check / unknown`，不跳过条件，也不再抛出 500。
- 对代数数反例暂不能独立精确导出的情况，保留 `unknown`，不误报已证明。回归中另有独立有理数反例确认圆弧反射情形。
