## 统一模型与支持范围

题目模型包含 `schemaVersion`、`version`、点/线段/圆、条件、目标、非退化要求及构造字段。当前构造字段必须为空；本版从明确的点坐标与关系建题，不接受隐藏构造。显示坐标不作为普遍证明的前提。

已取消8点、20条条件、32条线段的建题数量门槛。已编码关系含线段等长、中点、垂直、平行、三点共线、严格线段上的点、内角相等、圆、圆弧、定长、数值角度、长度比、相似、三角形内点、圆内外点及直线同侧/异侧；另支持角度值及加权距离和最小值目标。其他条件、任意表达式保存为文字，由 AI 继续分析；不将尚未编码的题目标为已精确核验。

求角会先尝试精确代数射线交点构造：两锚点规范化只用于相似不变量，固定坐标/固定长度题不适用该规范化捷径。正反射线、交点分支和全部原题条件共同决定候选集；超时、分支过多、连续分支或未能穷尽时退回未完成状态。当前构造预算为 12 点、2048 个分支、10 秒；这不是导入题目的点数上限。

最值证明包括加权项精确约简、多动点折线路径、连续直线反射及已实现的反演证书。数值搜索只提议候选；只有下界成立、所有保留条件下的联合取等存在，才标记已核验。排除端点、区域限制、点互异或中点联动均不能在取等检查中省略。

Z3 对这些关系进行精确编码；普遍分析时利用相似变换和反射不改变上述关系的性质，规范化一个非退化三角形的坐标系，以减少求解自由度。这不是把画面坐标当作已知条件。画板拖动求解不进行这种规范化，保留用户的坐标框架。

内角相等使用平方余弦关系及点积符号一致要求，避免把45度与135度判成相等。反例只接受由 SymPy 独立精确核验通过的有理坐标；尚不能独立核验的代数数模型显示当前无法判断。

Newclid 使用上述关系的已实现映射；内角相等作为输入前提尚不支持，会明确提示。搜索未找到不影响单独展示 Z3 的精确核验结果。中文文字/图片识题、用户补充条件、数值长度与角度现已接入；AI 与精确引擎的支持范围分开标注。NiceGeo 的8类关系、常用理由与高级脚本范围见独立接入记录。

## 版本与运行问题

- NetworkX 3.7 要求 Python >=3.12，因此本机使用 Python 3.12.16。
- Newclid 分发包的 YAML 导入需要单独补充 PyYAML 6.0.3；运行问题与兼容处理已记录。
- JSXGraph npm exports 未导出 CSS 子路径，使用从实际包复制的原始样式文件并保留版权说明。
- 首次依赖安装时系统缓存目录不可写，已将 npm、uv、Python 与绘图缓存放在项目内部。
- 构建仍提示 JSXGraph 的 JessieCode 模块含 eval、画板分块较大；应用不开放 JessieCode 或任意代码输入。此项为后续打包优化，未修改上游库。
- NiceGeo Windows 工具链、结构化 NCG 适配及真实 CLI / HTTP 检查已完成。当前仅保留本机运行，部署用 Docker 配置已移除。
